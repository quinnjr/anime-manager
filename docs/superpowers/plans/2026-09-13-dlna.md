# DLNA Server Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve the library over LAN via DLNA with direct-play plus an ffmpeg remux fallback, toggled from Settings.

**Architecture:** New `dlna.rs` module owns SSDP + ContentDirectory DIDL + range HTTP serving; reads `db.rs` live per request; managed from `lib::run` as a tokio task guarded by single-instance; frontend talks via three commands plus a `dlna-changed` event.

**Tech Stack:** Rust 1.88 (let-chains), tokio (existing features: net, io-util, time, sync, macros, process), rusqlite via `db.rs`, SvelteKit 5 runes frontend, no new crates in v1 (hand-rolled HTTP/1.1 + SSDP over `tokio::net::UdpSocket` / `TcpListener`).

**Spec:** `docs/superpowers/specs/2026-09-13-dlna-design.md`

## Global Constraints

- Rust 1.88+ required; let-chains are used in `commands.rs`, `db.rs`, `parser.rs`.
- Rust suite MUST run single-threaded: `cargo test --manifest-path src-tauri/Cargo.toml -- --test-threads=1` (player tests use process-global env).
- Tauri maps camelCase JS args to snake_case Rust params automatically.
- `src/lib/api.ts` is the only place that calls `invoke`; keep TS interfaces in step with `models.rs`.
- Serving never writes the DB except best-effort played-marking; never marks missing; never writes beside media.
- `display_title` is label-only; identity keys stay on ids / `parsed_title`.
- Non-UTF8 paths are skipped from browse and counted, never stored lossily.
- Only one instance may run (`tauri_plugin_single_instance` registered first); DLNA port is owned by that instance.
- No new async runtime, no new crates in v1; ffmpeg is optional at runtime via `$PATH`.

```rust
// src-tauri/src/dlna.rs
pub fn encode_id(kind: &str, id: i64) -> String { format!("{kind}:{id}") }

pub fn decode_id(s: &str) -> Option<(String, i64)> {
    let (k, v) = s.split_once(':')?;
    if k != "show" && k != "season" && k != "episode" && k != "root" && k != "shows" { return None; }
    let id: i64 = v.parse().ok()?;
    if v.starts_with('-') || v.starts_with('+') { return None; }
    Some((k.to_string(), id))
}

pub fn xml_escape(s: &str) -> String {
    let mut o = String::with_capacity(s.len());
    for c in s.chars() {
        match c {
            '<' => o.push_str("&lt;"),
            '>' => o.push_str("&gt;"),
            '&' => o.push_str("&amp;"),
            '"' => o.push_str("&quot;"),
            '\'' => o.push_str("&apos;"),
            _ => o.push(c),
        }
    }
    o
}

pub fn didl_for_episode(show_title: &str, season_no: u32, ep: &crate::models::Episode, urls: &[String]) -> String {
    let mut s = format!(
        "<item id=\"{}\" parentID=\"season:{}\" restricted=\"1\"><dc:title>S{:02}E{:02} {}</dc:title><upnp:class>object.item.videoItem</upnp:class>",
        xml_escape(&encode_id("episode", ep.id)), ep.season_id, season_no, ep.number, xml_escape(show_title)
    );
    for u in urls {
        s.push_str(&format!("<res protocolInfo=\"http-get:*:video/x-matroska:DLNA.ORG_OP=01\">{}</res>", xml_escape(u)));
    }
    s.push_str("</item>");
    s
}
```

```rust
pub fn browse(db: &crate::db::Db, object_id: &str) -> crate::error::Result<String> {
    use crate::models::ShowSort;
    let (kind, id) = decode_id(object_id).unwrap_or(("root".into(), 0));
    match kind.as_str() {
        "root" => {
            let mut s = String::from("<container id=\"shows:0\" parentID=\"root:0\" restricted=\"1\"><dc:title>Shows</dc:title></container>");
            let _ = id;
            Ok(s)
        }
        "shows" => {
            let mut s = String::new();
            for c in db.list_shows("", ShowSort::Title)? {
                s.push_str(&format!("<container id=\"{}\" parentID=\"shows:0\" restricted=\"1\"><dc:title>{}</dc:title></container>",
                    xml_escape(&encode_id("show", c.id)), xml_escape(&c.display_title)));
            }
            Ok(s)
        }
        "show" => {
            let d = db.get_show(id)?;
            let mut s = String::new();
            for se in &d.seasons {
                let label = se.title.clone().unwrap_or_else(|| format!("Season {}", se.number));
                s.push_str(&format!("<container id=\"{}\" parentID=\"{}\" restricted=\"1\"><dc:title>{}</dc:title></container>",
                    xml_escape(&encode_id("season", se.id)), xml_escape(object_id), xml_escape(&label)));
            }
            Ok(s)
        }
        "season" => {
            // find parent show by scanning shows (small N in tests; paginate later if needed)
            let mut s = String::new();
            for c in db.list_shows("", ShowSort::Title)? {
                let d = db.get_show(c.id)?;
                for se in &d.seasons {
                    if se.id == id {
                        for ep in &se.episodes {
                            if ep.status == crate::models::EpisodeStatus::Missing { continue; }
                            let u = format!("/media/{}", encode_id("episode", ep.id));
                            s.push_str(&didl_for_episode(&d.display_title, se.number, ep, &[u]));
                        }
                    }
                }
            }
            Ok(s)
        }
        _ => Ok(String::new()),
    }
}
```

```rust
pub fn remux_path(cache: &std::path::Path, episode_id: i64, size: i64, mtime: i64) -> std::path::PathBuf {
    cache.join(format!("{episode_id}-{size}-{mtime}.mp4"))
}
pub fn should_mark_played(bytes_sent: u64, total: u64) -> bool {
    total > 0 && bytes_sent * 100 >= total * 85
}
// In the /media/ handler:
// - second <res> advertised only if `which ffmpeg` succeeds (check `tokio::process::Command::new("ffmpeg").arg("-version").output()` once at startup, cache bool).
// - on remux <res> request: if cached file missing, run
//   `ffmpeg -y -i <src> -c:v libx264 -preset veryfast -c:a aac -movflags +faststart <dst>.tmp` then rename;
//   subtitle strategy decided by `ffprobe` stream check at this point (burn ASS vs mov_text) — record choice in code comment.
// - after a completed GET, if should_mark_played -> db.set_status(episode_id, Played) via existing
//   set_status path (preserves prev_status); never mark Missing; failures only log.
// - cache eviction (LRU, 2 GB cap): after each remux write, list cache/*.mp4 by mtime,
//   delete oldest until total <= 2_147_483_648 bytes. Call it from the same handler.
```
